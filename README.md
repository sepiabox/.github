# Sepiabox

**Ask your photos.** Sepiabox brings a family's photos and videos together from external drives, Google Photos, Google Drive, OneDrive and phones, and finds any moment when you ask.

Early development, tested by one family before anyone else. Open source.

| Repository | What it is |
|---|---|
| [sepiabox-platform](https://github.com/sepiabox/sepiabox-platform) | The app: web, processing pipeline, local ingestion (.NET) |
| [sepiabox-infra](https://github.com/sepiabox/sepiabox-infra) | Azure account setup, budget and emergency stop |
| [sepiabox-site](https://github.com/sepiabox/sepiabox-site) | The website at sepiabox.com |
| [sepiabox-brand](https://github.com/sepiabox/sepiabox-brand) | Name, logo, colors and type |
